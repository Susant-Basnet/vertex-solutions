A strict flat-design block theme for business, consulting and technology websites.

== Description ==

VERTEX Solutions is a Full Site Editing theme with a one-page business homepage built from editable block patterns, plus templates for pages, single posts, archives, search results and 404 errors. Colors, typography, spacing and borders are defined in theme.json and reused by style.css through CSS variables.

= Contact form =
The contact section is designed for the free Contact Form 7 plugin. A ready-to-paste form template is in docs/contact-form-7-template.txt.

== Installation ==

1. Go to Appearance > Themes > Add New > Upload Theme and upload the zip.
2. Activate the theme.
3. Install and activate Contact Form 7, then create a form titled "Contact form 1" using docs/contact-form-7-template.txt.
4. Create or choose a page and set it as the homepage under Settings > Reading (the front page template is used automatically).

== Frequently Asked Questions ==

= Can I edit the homepage sections? =
Yes. Open Appearance > Editor > Templates > Front Page, or insert the "VERTEX Solutions" patterns on any page.

= The contact form does not show =
Install and activate Contact Form 7 and create a form titled "Contact form 1", or change the shortcode in the Contact section.
